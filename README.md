# space_flighter

A 2D space shooter game built with Python and Pygame.

Take control of your spaceship, fight different types of enemies, collect power-ups, survive increasingly difficult waves, and defeat powerful bosses!

🎮 Features

- Player Controls: Touch-based movement and continuous shooting.
- Enemy Types: Normal, Fast, Tank, and Zigzag enemies.
- Boss Battles: Powerful bosses with health bars and multiple attacks.
- Weapon Upgrades: Collect power-ups to upgrade your weapons.
- Health System: Three health points with temporary invincibility after taking damage.
- Difficulty Progression: Enemies become more challenging as you advance.
- Particle Effects: Explosions, shooting effects, and damage animations.
- High Score System: Your best score is saved locally.
- Animated Graphics: Animated spaceship, enemies, and explosions.

🛠️ Technologies Used

- Python
- Pygame
- Random
- Math
- OS

🕹️ How to Play

1. Tap the screen to start.
2. Drag your finger to move your spaceship.
3. Hold your finger to shoot continuously.
4. Destroy enemies and avoid collisions.
5. Collect power-ups to improve your abilities.
6. Defeat bosses and try to achieve a new high score!

📦 Installation

Make sure Python is installed, then install Pygame:

pip install pygame

Run the game:

python main.py
